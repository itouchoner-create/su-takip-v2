
# Aytaç Öner Su Takip - GitHub APK

1. Bu klasörü GitHub'da yeni repo oluşturup içine yükle
2. Actions sekmesine git -> Build APK -> Run workflow de
3. 6-7 dk sonra APK hazır olur -> Artifacts'ten indir

- Siparişler listesinde SİL butonu var
- Emanet listesi içinde VER/AL butonları var
